## Common learning-rate calibration

Precompute one common PCD base rate from the immutable raw-gradient snapshot before any screen. Let `P` be the measured initial trainable-parameter L2 norm and `Gmax` the maximum raw chemistry-gradient L2 norm over the 27 frozen pairs. The PCD final direction has norm `||g_chem||`; the installed RAdamW (`betas=(0.9,0.999)`) is unrectified for its first two updates, so the first update is proportional to that direction and the second bias-corrected first moment is a convex combination of the two raw directions. Set `lr0 = 0.009 * P / (Gmax + 0.01 * 1.01 * P)`, using the existing `weight_decay=0.01`; the 0.009 target leaves margin below the 0.01 update-to-parameter norm cap. The reported chemistry median is `1762.87`, so this bound is at most about `1.09e-4` and will be lower if the observed maximum exceeds the median. This is a deterministic scale bound, not an assumption that Nash's `0.01` rate transfers to PCD. Do not inspect or process the raw tensor snapshot until Gate 1 closes.

Validate the derived common rate with two updates for each tau, from identical fresh predopt initialization, first two manifest entries, and the same 150-update cosine horizon. Verify finite gradients/losses/parameters/state, correct EMA count and cursor/scheduler progress, and a maximum measured per-update parameter delta divided by `P` no greater than `0.01`. Log paired task objective ratios and optimizer-vs-PCD direction geometry; do not use a weighted loss or require improvement in the two-step gate. An objective change is a trigger only if it is clearly pathological. If measured delta exceeds the cap or there is a clear numerical blow-up, reduce the single common rate deterministically (halve it) and repeat all six tau checks; do not assign rates per tau or stop at an arbitrary grid endpoint. Preserve and validate canonical exact-zero branches rather than forcing a nonzero delta.
