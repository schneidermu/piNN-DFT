# PCD integration short spec

## Contract

Use Dara Varam and Mohamed I. AlHajri, “Not All Objectives Are Born Equal: Priority-Constrained Descent for Hierarchical Multi-Objective Optimization,” TMLR (September 2026), [OpenReview record](https://openreview.net/forum?id=HT01yGHLEt), arXiv:2606.29521v2. The audited paper PDF SHA-256 is `8e6c03dd8edc2836057f748761c98b352600819cce3e0bf2c0fb6ccef7878c65`. Pin the official [MIT-licensed implementation](https://github.com/DaraVaram/priority-constrained-descent) at `e9afdbc9f4cb09343934eadb31dc72ea5ebac9b0`; retain attribution to both authors. The source contract and its edge cases are recorded in [source_contract.md](source_contract.md); its upstream suite passed 88 tests.

For each update, use global raw gradients in fixed order `chem` (primary), `exc`, `op`. Maintain each task’s EMA of squared raw-gradient norm, `vᵢ ← βvᵢ+(1−β)||gᵢ||²`; bias-correct with shared count `t`; set `sᵢ=1/sqrt(v̂ᵢ+eps)` and `g̃ᵢ=sᵢgᵢ`. Defaults are `β=0.999`, `eps=1e-8`; screen `tau ∈ {0,.005,.01,.02,.05,.10}`. Solve `min_d ½||d−g̃chem||²` subject to `g̃ⱼ·d ≥ tau||g̃ⱼ||²` for `j ∈ {exc,op}`. Match the source’s deterministic K=3 active-set enumeration, tolerance `1e-9`, and feasibility checks. `tau=0` is always feasible. Rescale the result to `||gchem||`. Exact-zero secondary gradients impose no constraint. If the primary gradient or QP direction is zero, return the exact zero direction after updating EMA state; still follow the existing optimizer/scheduler cadence. If constraints are infeasible, drop all secondary constraints and use the primary direction. Do not claim exact scale invariance at finite `eps`.

## Integration/state invariants

Add `method="pcd"` to the existing aggregator return interface `(joint_gradient, diagnostics, next_state)`. State identifies `method="pcd"` and contains canonical task order, `tau`, finite task-aligned EMA values `v`, shared `t`, `beta`, and `eps`; reject a mismatched resume state. Run EMA/QP only after `materialize_task_zeros` and `average_raw_task_gradients`, so every rank sees identical inputs and advances identical state. Reuse existing optimizer, cosine scheduler, chunked objective factories, flatten-free Gram/diagnostic logging, checkpoint cursor, and per-rank RNG machinery. Do not add another trainer or concatenate model-sized vectors.

Protocol metadata must bind the PCD citation, paper hash, upstream repository/commit/license, `tau`, `beta`, `eps`, QP tolerance, primary/task order, exact hashes for the current critical training files (`lap_moo_protocol.py`, `lap_moo_training.py`, `lap_moo_optimizers.py`, `moo_aggregators.py`, and `train_lap_moo.py`), `world_size`, both chunk sizes, and existing checkpoint/data/dispersions/manifest identities. Record the startup Git revision in the run-level summary alongside the exact source-file hashes already bound by the protocol; do not put mutable repository HEAD into immutable checkpoint metadata. Preserve both canonical embedded and file-byte manifest hashes. Reuse the 27-reaction/15-system panel and 150-update cosine-to-10%-of-base convention, RAdamW parameter groups/betas/epsilon/decay, float32 model inputs, point chunk 256, AO-cache chunk 4096.

## Acceptance and non-goals

The six matched cursor-25 screens share one predeclared PCD base learning rate, or a minimal stability calibration declared before any screen; do not silently assume `0.01` or hand-normalize the direction. A candidate meets the existing training-panel success rule only when median ratios to predopt are `<1` for **all three** tasks; retain the `100×` per-row stability ceiling. Advance at most two or three candidates to cursor 100, matched panels, and SCF route checks. Chemistry leads tradeoff descriptions. Report no winner if no candidate passes and make no statistical superiority claim.

No architecture, objective/loss, dataset identity, S5, Nash/fairness, or optimizer-family redesign; no historical artifact mutation, diet/Slurm workflow, or all-90 AO claim. T1–T8 in [tickets.md](tickets.md) are the implementation gate. Do not begin code until this spec and those tickets are accepted.
