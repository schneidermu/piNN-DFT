# Next optimization strategy: vector Armijo on the fixed PCD ray

## Recommendation

Test a componentwise multiobjective Armijo backtracking rule first, scaling the already-computed PCD direction by one scalar step length. Keep the released PCD QP, task order (`chem`, `exc`, `op`), tau=.02, EMA (beta=.999, eps=1e-8), direction normalization, model, losses, and sampled batch unchanged. For the first causal test use the plain-SGD control path that exhibited the failure; do not mix in RAdamW, momentum, weight decay, or a schedule. This is a globalization check around the existing direction, not a new objective or architecture.

This is the best causal match to the evidence. At b20d153, the second same-sample SGD step had favorable local task-gradient/update dots, yet chemistry rose 56.64x and E_xc 21.78x, while the AO operator decreased. Thus local directional descent did not control the finite step. The raw PCD ray already has positive dot products with all three minimized task gradients; a componentwise Armijo test asks the smallest unanswered question: does shortening that exact ray yield actual same-sample decreases in chemistry, E_xc, and operator loss? Chemistry remains primary because PCD direction construction remains chemistry-primary and the chemistry condition is mandatory. Fliege and Svaiter’s multicriteria steepest-descent method uses backtracking Armijo acceptance componentwise for the objective vector [primary paper](https://doi.org/10.1007/s001860000043).

## Comparison and causal fit

| Candidate | Fit to this evidence | Why it is not first |
|---|---|---|
| **Vector Armijo line search — first** | Directly tests finite-step overshoot on a direction whose three local slopes are already favorable. It changes only the scalar step and gives an interpretable accepted step plus three measured loss changes. | Same-batch acceptance is a local diagnostic, not a held-out chemistry claim. It does not repair an RAdamW proposal whose actual direction has an adverse task slope. |
| Multiobjective trust region | A sound next globalization family: vector model decrease and actual/predicted reduction can control both step and local-model reliability. Carrizo, Lotito, and Maciel formulate nonconvex multiobjective trust-region globalization with vector decrease and radius updates [primary paper](https://doi.org/10.1007/s10107-015-0962-6). | More machinery (models, radius, agreement ratios); it is not needed to test whether reducing this one known step fixes the observed failure. Use it if line-search outcomes show poor model agreement or highly unstable radii/steps across updates. |
| BB/spectral multiobjective descent (BBDMO) | Chen, Tang, and Yang use BB scaling in direction construction to address objective imbalance and report that ordinary multiobjective Armijo can become very small for that reason [primary paper](https://doi.org/10.1016/j.ejor.2023.04.022). | It changes the direction/QP scaling, whereas the direct evidence isolates a too-large finite step along a direction with favorable dots. Consider only if repeated vector Armijo runs are consistently throttled by one objective’s scale. |
| Stochastic variance reduction / larger balanced batches | These reduce gradient noise or improve gradient signal-to-noise; SVRG is a finite-sum variance-reduction method [Johnson & Zhang, primary paper](https://proceedings.neurips.cc/paper/2013/hash/ac1dd209cbcc5e5d1c6e28598e8cbbe8-Abstract.html), and adaptive big-batch methods target signal-to-noise [De et al., primary paper](https://proceedings.mlr.press/v54/de17a.html). | The catastrophic rise occurred on the same sample even though its local dots predicted descent, so sampling variance is not required to explain it. These methods cost more and confound this first finite-step test. If stochastic line search is later needed, Paquette and Scheinberg analyze adaptive-accuracy stochastic Armijo [primary paper](https://doi.org/10.1137/18M1216250). |

## Smallest falsification protocol

1. Reproduce the already reported tau=.02 plain-SGD control from its exact fresh predopt checkpoint and seed-41 stream, through the first update, to the offending second-step starting parameters. Use the exact same AE17/H2 sample for the gradient and candidate loss evaluations. Retain the reported common starting learning rate `eta0 = 6.632573669086685e-7`; keep the PCD EMA, epsilon, QP, and raw-gradient rescaling identical.
2. At that second-step point, compute the three gradients and PCD direction `d` once. Cache each current loss `F_i(theta)` and slope `s_i = g_i dot d` from the same sample. Confirm `s_i > 0` for chemistry, E_xc, and operator before searching. Do not recompute `d` between trials.
3. For `j = 0,...,12`, evaluate all three original task losses at `theta_j = theta - eta0 * 2^-j * d`, using deterministic evaluation and the same frozen input/sample. Accept the first common step satisfying, for every task `i`, `F_i(theta_j) <= F_i(theta) - 1e-4 * eta0 * 2^-j * s_i`. This is one vector Armijo condition; rho=.5, c=1e-4, maximum 12 halvings. Record exact chemistry, E_xc, and operator changes, accepted j/eta, predicted reductions, actual step norm, and forward-evaluation count. Apply at most that one accepted update. If none passes, record rejection (zero update); do not substitute another optimizer in this diagnostic.

## Decision signatures and cost

- **Overshoot supported:** `j=0` fails as reported, but a shortened step passes all three conditions with negative measured changes in chemistry, E_xc, and operator. That shows a scalar finite-step correction can preserve this PCD ray and produce actual common descent on the fixed sample. It does not establish held-out or multi-step improvement.
- **Overshoot-only explanation weakened at useful scales:** no step passes in 12 halvings, or one objective remains non-decreasing through the floor. First check deterministic loss/gradient/sample identity and floating-point resolution. A scalar shrinkage on this ray is then not demonstrated as an effective remedy; do not claim the failure is sampling noise from this same-sample result.
- **Next trigger:** if a common step passes, run a small paired tau=.02 multi-update replay with this identical acceptance rule and the locked stream, reporting accepted-step distribution and all three loss trajectories against fixed/Nash controls. Only after that succeeds, test the RAdamW proposal: check its three actual directional slopes first, since a scalar line search cannot repair an update ray with an adverse component. If acceptance repeatedly requires extreme shrinkage because one task bottlenecks, evaluate BBDMO; if outcomes instead vary across independent balanced samples, evaluate larger batches/variance reduction; if model agreement or accepted steps are unstable across updates, evaluate vector trust-region globalization.

Cost is one direction/QP and up to 13 candidate loss-vector evaluations, with no trial gradients or new optimizer state. In this deterministic same-sample check each candidate can reuse the existing task outputs and AO path. The next full training test will pay extra forward evaluations per backtrack; the first diagnostic is intentionally only one failed step replay. A same-sample pass is empirical evidence on that sample only; the frozen 27-reaction / 15-system screen remains necessary for chemistry and operator generalization.
