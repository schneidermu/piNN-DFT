# Solver 4: first globalization experiment for PCD overshoot

## Recommendation

Test a **same-batch, componentwise multiobjective Armijo backtracking rule on a single fixed PCD ray first**. For this first falsification, use the direction-preserving plain-SGD replay that produced the reported second-step blow-up. Keep the PCD task order, chemistry-primary direction, tau=.02, EMA, losses, model, and data fixed; search only one shared multiplier on that already-computed parameter step. This is the smallest intervention that distinguishes an overlong finite step from a bad PCD direction or stochastic-gradient noise.

Accept the largest dyadic fraction of the proposed step satisfying the standard vector Armijo inequalities for **all three existing losses**. Thus chemistry remains the PCD primary task while E_xc and AO-operator losses must also receive sufficient actual decrease; no scalarized merit or new objective is introduced. Fliege and Svaiter establish this non-scalarized multicriteria steepest-descent / Armijo framework and its Pareto-stationarity convergence result under smoothness assumptions ([2000 paper, DOI](https://doi.org/10.1007/s001860000043)). This is an empirical minibatch safeguard here, not a claim that their deterministic convergence theorem transfers to a neural training run.

## Why this should be first

At b20d153 the distinguishing evidence is not only the RAdamW direction rotation: on the same-sample SGD control, the optimizer preserves the PCD direction almost exactly, all three gradient–update dots predict decrease, yet the second step raises chemistry 56.64× and E_xc 21.78× while lowering operator loss. That is direct evidence of nonlinear finite-step overshoot along a locally favorable direction. A line search evaluates the actual nonlinear losses on that very ray, so it tests the alleged cause with no direction, sampling, or architecture confound. It is also trainer-compatible: one scalar multiplies the already-produced update and trial evaluations do not mutate optimizer, EMA, RNG, or checkpoint state.

The cited multicriteria Armijo condition is componentwise: for update `s` and trial fraction `a`, require `L_i(theta + a s) <= L_i(theta) + c a grad(L_i)^T s` for each task `i` (here `c=1e-4`). With PCD's common direction and tau=.02, the frozen first-order terms should be negative for all three tasks; the test asks whether any usable finite fraction realizes them. Use one shared backtracking coefficient, `a = 1, 1/2, 1/4, ...`, so the PCD direction and relative task geometry are unchanged. Chemistry-first is preserved by retaining chemistry-primary PCD and reporting chemistry change first; the componentwise condition prevents buying chemistry reduction with E_xc/operator regression.

## Candidate comparison

| Candidate | Fit to evidence | Cost / reason not first |
|---|---|---|
| **Vector Armijo line search — first** | Directly tests whether shrinking the direction-preserving step fixes actual finite-step loss increases; cleanest falsification of overshoot. The established multicriteria scheme imposes Armijo decrease per component without scalarization. | Minimal code and one forward loss evaluation per trial fraction; no extra gradients or direction solve. It guarantees only same-sample decrease in this stochastic setting. |
| **Multiobjective trust region — second-line safeguard** | Also targets model-versus-actual nonlinear reduction and can adapt a radius when a ray is unreliable. Carrizo, Lotito & Maciel formulate vector predicted/actual reduction and radius globalization for nonconvex multiobjective optimization ([2016 paper, DOI](https://doi.org/10.1007/s10107-015-0962-6)). | Requires choosing/maintaining models, predicted-reduction and radius rules, plus a subproblem. More machinery than needed to test a single suspected too-long step. Escalate if ray backtracking accepts only unusably tiny steps or if no practical ray fraction gives three-task decrease. |
| **BB/spectral multiobjective descent (BBDMO)** | Chen, Tang & Yang propose objective-wise BB curvature scaling to address objective imbalance and report that standard multiobjective Armijo can become very small ([2023 EJOR paper, DOI](https://doi.org/10.1016/j.ejor.2023.04.022)). | Its target is imbalance/small steps and it changes the task direction construction. The present diagnostic has a large finite-step blow-up even with direction-preserving SGD, so changing directions first would not isolate overshoot and would depart from validated PCD geometry. Consider only after a step-length study shows persistent objective-imbalance limits rather than curvature overshoot. |
| **Variance reduction / larger balanced batches** | Relevant if task gradients or acceptance decisions vary substantially with sampling. SVRG explicitly reduces stochastic-gradient variance in finite-sum problems ([Johnson & Zhang, NeurIPS 2013](https://proceedings.neurips.cc/paper_files/paper/2013/hash/ac1dd209cbcc5e5d1c6e28598e8cbbe8-Abstract.html)); stochastic MGDA addresses expectation-valued multiobjective losses ([Mercier, Poirion & Désidéri, 2018, DOI](https://doi.org/10.1016/j.ejor.2018.05.064)). | Same-sample overshoot already exists, so variance reduction cannot be the first explanation or falsification. Larger balanced batches cost more and test estimator noise rather than the demonstrated fixed-batch nonlinear step. Revisit if accepted fractions or loss changes are unstable across frozen balanced batches. |

## Minimal protocol

1. Reproduce the report's exact fresh predopt → first plain-SGD PCD update → second AE17/H2 same-sample step, using its seed, order, batch, dtype, tau=.02, EMA state, and common `eta=6.632573669086685e-7`. Do not change model, objective code, or optimizer for this diagnostic.
2. At the second-step base parameters `theta1`, compute the three existing task gradients and one canonical PCD direction once. Let `s0 = -eta*d` be the exact proposed SGD parameter delta. Keep the task batch and any model stochastic state fixed; do not advance RNG or EMA while trialing.
3. Evaluate the actual triplet `(chem, E_xc, AO operator)` at `theta1 + a*s0` for `a=2^-j`, `j=0,...,12`, largest first. Accept the first fraction satisfying the three componentwise Armijo inequalities above. Compare actual loss ratios and absolute changes to `theta1`; record every trial, directional prediction, and selected fraction. Apply only the selected step after deciding; do not apply/revert trial steps.
4. Predeclare success as an accepted fraction with all three actual losses lower than their `theta1` values and all three Armijo inequalities passing, with chemistry reduction reported first. A pass at a materially useful fraction falsifies “this direction intrinsically causes the observed second-step blow-up” and supports finite-step overshoot as a correctable cause. If only a very small fraction passes, record the resulting chemistry decrease and effective shrinkage; it may be mathematically successful but operationally too costly. If none passes through `2^-12`, audit determinism, loss/gradient alignment, and frozen state first—the local dots and differentiability imply sufficiently small fractions should decrease each loss.

## Interpretation and next trigger

This one-step result is a mechanistic falsification, not evidence of generalization or a training-gate pass. If it finds a useful common decrease, next test the same accept/reject rule on the **actual RAdamW proposed parameter delta** on one matched update; its observed rotation means one cannot infer its componentwise derivative signs from the PCD direction alone. If the ray needs extreme shrinkage or gives no practical progress, test a multiobjective trust-region globalization next. If frozen-batch acceptance is useful but changes across balanced batch draws, then test batch enlargement / variance reduction. Do not start with BBDMO unless subsequent evidence specifically points to objective imbalance or small-step stalling.
