**Status: GO for the T4 implementation gate.** The independent source review found no remaining blocker, and the focused T4 suite now passes 16 tests in 6.07 seconds; Ruff is clean. This includes a two-rank Gloo case where rank-local losses disagree but both ranks choose the shared step using global task means, plus distributed checkpoint/resume.

The engine uses the globally averaged raw task gradients to form `Delta0 = -alpha0*d`, checks finite strict negative slopes for all three tasks, and tests each raw loss against `L_i(base) + c*t*s_i`; acceptance also requires strict actual decrease in all three tasks. Trial objectives take equal per-rank task-scalar means after synchronized failure checks. Each trial restores the complete model state and post-gradient RNG before the next probe. Rejection restores the pre-update model/RNG and leaves the incoming PCD EMA untouched; acceptance commits the evaluated candidate tensors and returns the one computed EMA update. Direct mode has no optimizer or scheduler and applies no weight decay.
