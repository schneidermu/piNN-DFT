# Solver 3 — next falsification experiment

## Recommendation

Test **a single full-cycle, database-balanced gradient accumulation while keeping chemistry-primary PCD and the existing vector Armijo unchanged**. Replay from the frozen cursor-2 checkpoint, recomputing the task gradients over one complete 27-entry training-manifest cycle (three reaction groups from each of nine databases and the manifest's 15-system cycle), then form exactly one canonical PCD direction. This is the smallest experiment that distinguishes whether the NCCE31/BH chemistry-ascent proposal is a sample-composition effect from a persistent PCD direction-selection failure. It preserves the hierarchy, data definitions, weights, tau, and architecture.

The failure itself is established: at cursor 2, PCD's proposal has an adverse chemistry slope and favorable E_xc/operator slopes, so Armijo correctly performs zero trials. But the same batch has a strict common-descent witness. Thus the single-row state is not Pareto-critical, and shrinking PCD's ray cannot fix its adverse chemistry slope. The question is whether that direction sign persists under a better estimate of the existing task-gradient means. The first-two-update panel is mixed: chemistry median ratio 1.0145 with 11/27 wins, E_xc 0.6487 and operator 0.9551 with 27/27 wins each. Two updates do not establish the stream or panel mean.

The literature supports the experiment class: Mercier, Poirion, and Désidéri formulate stochastic multiobjective objectives as expectations and analyze a stochastic multiple-gradient method ([EJOR 2018](https://doi.org/10.1016/j.ejor.2018.05.064)). Jain et al. analyze mini-batching as variance reduction for stochastic gradients in least-squares regression ([JMLR 2018](https://www.jmlr.org/papers/v18/16-595.html)); that result motivates accumulation but is not a theorem for this neural model. Johnson and Zhang's SVRG is an established finite-sum variance-reduction alternative ([NeurIPS 2013](https://proceedings.neurips.cc/paper_files/paper/2013/hash/ac1dd209cbcc5e5d1c6e28598e8cbbe8-Abstract.html)); use direct accumulation first because it is simpler and leaves the training rule unchanged.

## Minimal protocol

1. Load the exact direct-Armijo cursor-2 checkpoint and its immutable sampling manifest. Reproduce the stored NCCE31/BH proposal slopes once as a receipt check. Freeze model parameters/buffers, RNG, and EMA state for the diagnostic; do not advance or commit them.
2. Use the next complete 27-entry cycle defined by that same training manifest as one superbatch. It covers the manifest's 27 reaction groups (three per database across nine databases) and its 15 mRKS systems at their existing cycle frequencies. Preserve the current task-specific reductions, Minnesota database/group weights, and operator system weights exactly; accumulation must estimate the same three objectives, not equalize database weights beyond their existing definitions.
3. Compute the three accumulated raw gradients and apply the unchanged PCD implementation once with `tau=.02`, `beta=.999`, `eps=1e-8`, current EMA state, and task order chem/E_xc/operator. Record PCD's actual proposal slope for each full-cycle task mean. Also compute the strict common-descent feasibility diagnostic on these same accumulated gradients; this distinguishes an adverse PCD choice from a genuine first-order conflict in the broader batch.
4. If all three PCD slopes are strict descent, apply the existing vector Armijo to that same full-cycle empirical objective, with the recorded `alpha0`, `c=1e-4`, `rho=.5`, and existing cap. Trial evaluations use precisely the examples and weights used for the accumulated gradients. Record the chosen multiplier and actual/predicted changes for each loss. Do not commit a parameter/EMA update. This is one diagnostic replay, not continuation training or a panel success claim.

## Falsification signatures and cost

- **Supports sample-composition sensitivity:** the original row retains its adverse chemistry slope, but PCD on the full-cycle means has strict chemistry/E_xc/operator descent and vector Armijo accepts an actual decrease in all three. This supports larger balanced accumulation as the next training mechanism; it does not establish held-out or long-run gains.
- **Supports direction-selection failure:** the full-cycle batch still has a strict common-descent witness, but canonical PCD has an adverse chemistry slope. Sampling across the available cycle did not fix the primary direction. Do not count this as line-search failure.
- **Shows a broader first-order conflict:** no strict common-descent witness exists for the full-cycle gradients. A common-descent algorithm would then be expected to stop on that empirical objective; do not claim a batch-size change can guarantee simultaneous decreases.
- **Step-size remains material:** full-cycle PCD has three negative slopes but the existing Armijo rejects every tested step. That separates step globalization from the present no-trial event; record the rejection without changing the direction or objectives.

This costs one accumulated gradient pass over the existing cycle and, only when slopes qualify, the already implemented loss-only line-search trials. The limitation is that one deterministic cycle diagnoses its empirical stream objective; it is not a population estimate.

## Why not the other first tests

A literature-native MGDA/common-descent direction plus vector Armijo is directly relevant: Désidéri's MGDA constructs a common descent direction when the point is not Pareto-stationary ([2012 primary paper](https://doi.org/10.1016/j.crma.2012.03.014)); Fliege and Svaiter's multicriteria steepest descent supplies a componentwise Armijo framework ([2000 paper](https://doi.org/10.1007/s001860000043)). However, the measured minimum-norm raw-gradient convex-hull witness here weights chemistry about 0.00142, E_xc 0, operator 0.99858, with very small chemistry slope. That symmetric direction does not encode chemistry priority, so it is not the cleanest first training test.

BBDMO uses Barzilai–Borwein scaling in the direction subproblem to address objective imbalance (Chen, Tang & Yang, [EJOR 2023](https://doi.org/10.1016/j.ejor.2023.04.022)). It changes direction geometry and is better motivated by persistent imbalance or repeated tiny accepted steps; the present no-trial event is one adverse chemistry slope. A multiobjective trust region uses vector predicted/actual reduction and radius updates (Carrizo, Lotito & Maciel, [Mathematical Programming 2016](https://doi.org/10.1007/s10107-015-0962-6)); it cannot repair an adverse chemistry slope on the same ray and adds model/subproblem machinery. The earlier `alpha0/32` rescue is not evidence of chronic tiny steps.

**Next trigger:** if strict common descent remains feasible on the full-cycle gradients while canonical PCD still proposes chemistry ascent, then test a literature-native common-descent method with the validated vector Armijo as a diagnostic. Only call a candidate successful if actual chemistry, E_xc, and operator losses all decrease, with chemistry reported as primary; do not claim that symmetric MGDA itself preserves the hierarchy.
